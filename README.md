# MyTUYA Smart Dashboard - instalační balíčky

Veřejné instalační balíčky aplikací MyTUYA Smart Dashboard. Webová aplikace je dostupná na https://mytuya.com.

## LG webOS

- [Vydané verze a soubory IPK](https://github.com/macikm/mytuya-releases/releases)
- [Návod k instalaci na LG webOS](INSTALL-WEBOS.md)
- [Popis aplikace](https://www.martinmacko.cz/mytuya-dashboard/)

Releases pro LG mají tagy ve tvaru `webos-v1.0.0`. V části Assets stáhněte soubor `.ipk`, nikoli automaticky generovaný archiv Source code.

Tento repozitář slouží k distribuci instalačních balíčků. [První vydání pro LG webOS 1.0.0](https://github.com/macikm/mytuya-releases/releases/tag/webos-v1.0.0) je dostupné ke stažení.
